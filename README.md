# Accessibility_App
The accessibility app sorts and prints the top 10 accessible games (based on age requirements, languages, price, and platform) for all games in the steam.csv file for each genre, allowing the user to input which genre they'd like to sort through.
> A course project for **MIST 4600: Computer Programming in Business** at the University of Georgia's Terry College of Business (Fall 2026).

## Problem
Accessibility App helps Steam game customers select which game to buy off of the Steam Market. However, when searching for games, it can be hard to find a game that matches the requirements you meet. With the Accessibility App, users are able to easily parse through all games in the steam.csv file and sort through them by genre, while sorting them by accessibility score, which is calculated using age requirements, languages available, price, and platforms available. 

## What it does
My app answers three questions:
1. **All-Age Games:** Which genre includes the highest share of all-age games?
2. **Affordable Games by Genre:** Which games are in each genre are most affordable? 
3. **Languages:** Which games have the most languages?

## Data
The [Steam Games Dataset](https://www.kaggle.com/datasets/artermiloff/steam-games-dataset) on Kaggle, collected in March 2025. The dataset is shared under the MIT License by its creator, artermiloff. This repo uses `steam_games.csv`, a smaller file made for the course: the 1,000 games with the most reviews.
